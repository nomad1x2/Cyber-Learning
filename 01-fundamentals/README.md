## Scripting projects
 
Scripts located in [`05-scripting-projects/`](../05-scripting-projects/).
 
| Script | Description |
|--------|-------------|
| [`dir_check.sh`](../05-scripting-projects/bash/dir_check.sh) | Checks if a target directory exists; if not, creates it. Then checks for a specific file inside; creates it if missing. Prints status at each step and confirms any creation. Ends with a recursive `ls` of the directory. |
| [`umask_calc.sh`](../05-scripting-projects/bash/umask_calc.sh) | Calculates and displays umask configuration based on either argument or system config, for both directory and file. Also displays associated symbolic permissions. |
